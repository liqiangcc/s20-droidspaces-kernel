# Scope

## In scope

- exact SM-G9810 firmware/source mapping;
- stock Samsung 4.19 kernel reproducibility;
- minimal DroidSpaces-required config adaptation;
- boot artifact verification and rollback preparation;
- staged real-device validation after manual approval.

## Out of scope unless separately justified

- custom ROM development;
- unrelated performance tuning;
- KernelSU/SUSFS integration;
- disabling Samsung security features for convenience;
- modem/CSC/vendor/system changes;
- automatic device flashing;
- destructive bootloader/repartition operations.
